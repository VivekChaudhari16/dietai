# 🥗 DietAI — AI-Powered Diet Recommendation System

An end-to-end machine learning system that recommends personalized diet plans based on a person's **BMI, cholesterol, blood sugar, blood pressure, and activity level** — deployed as an interactive Streamlit dashboard.

## 📌 Overview

DietAI takes a user's health metrics and predicts one of **7 personalized diet categories** (e.g. Diabetic-Friendly Low-Carb, Heart-Healthy Low-Cholesterol, Weight-Loss Calorie-Deficit, High-Protein Athletic, etc.) using a machine learning model trained on a 10,000-record health dataset.

## ✨ Features

- 🔮 **Interactive Prediction Tool** — enter your health profile via sliders and get an instant diet recommendation with confidence scores
- 📊 **Data Explorer** — visualize dataset distributions, correlations, and diet-class breakdowns
- 🤖 **Model Performance Dashboard** — compares Random Forest, XGBoost, and Gradient Boosting side-by-side with cross-validation scores, best hyperparameters, and feature importance
- 🎨 Clean, modern UI built with Streamlit + Plotly

## 🧠 Machine Learning Pipeline

| Stage | Details |
|---|---|
| **Data** | 10,000-row health dataset — Age, Gender, Height, Weight, BMI, Cholesterol, Blood Sugar, Systolic BP, Activity Level |
| **Feature Engineering** | Clinical risk bands (BMI category, cholesterol risk, glucose risk) + composite "Metabolic Load" score |
| **Models Compared** | `RandomForestClassifier`, `XGBClassifier`, `GradientBoostingClassifier` |
| **Model Selection** | 5-fold `StratifiedKFold` cross-validation + `GridSearchCV` hyperparameter tuning, selected on weighted F1 |
| **Deployment** | Best model serialized with `joblib`, served through a Streamlit app |

## 🚀 Getting Started

### 1. Clone & install
```bash
git clone https://github.com/<your-username>/dietai.git
cd dietai
pip install -r requirements.txt
```

### 2. (Optional) Regenerate data & retrain
The repo ships with a pre-trained model, so this step is optional.
```bash
python src/generate_data.py    # creates data/raw_data.csv
python src/train_model.py      # trains & saves models/best_model.pkl
```

### 3. Run the app
```bash
streamlit run app.py
```
Visit `http://localhost:8501`.

## ☁️ Deploy on Streamlit Community Cloud (free)

1. Push this repo to GitHub (see below)
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub
3. Click **New app** → select your repo → set main file path to `app.py`
4. Click **Deploy** — done in ~2 minutes

## 🗃️ Using a Real Kaggle Dataset

This repo ships with a **synthetic but realistically-distributed** dataset (correlated BMI/cholesterol/blood sugar/activity features) so the project runs out of the box. To use a real dataset instead:

1. Find one on Kaggle, e.g. search "diet recommendation dataset" or "health BMI cholesterol dataset"
2. Download the CSV and save it as `data/raw_data.csv`, matching these column names:
   `Age, Gender, Height_cm, Weight_kg, BMI, Cholesterol, BloodSugar, SystolicBP, ActivityLevel, DietRecommendation`
   (rename columns in the CSV, or edit `feature_cols` in `src/train_model.py` to match your schema)
3. Re-run `python src/train_model.py`
